# Temas Musicales

📌 En esta carpeta encontrarán temas musicales de los personajes, ambientes, lugares, magias y demás de Nombres Ocultos.

### Detalles

- También hay versiones preliminares, melodías sueltas y segmentos.
- Cada personaje tiene un tema musical simple. Las canciones largas son versiones extendidas adaptadas según el contexto en que se encuentra.
